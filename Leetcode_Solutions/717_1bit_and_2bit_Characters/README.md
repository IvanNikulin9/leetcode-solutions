# 717. 1-bit and 2-bit Characters

**Сложность:** Easy
**Ссылка:** https://leetcode.com/problems/1-bit-and-2-bit-characters/

## Описание
Есть массив из 0 и 1. Есть два типа символов: `0` (1 бит) и `10` или `11` (2 бита).
Нужно определить, заканчивается ли строка однобитным символом.

## Логика решения
Идем по массиву с шагом: если текущий бит `1`, перепрыгиваем через следующий (шаг 2), если `0` — шаг 1.
В конце проверяем, попали ли мы ровно на последний индекс.

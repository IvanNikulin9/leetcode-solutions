# 221. Maximal Square

**Сложность:** Medium
**Ссылка:** https://leetcode.com/problems/maximal-square/

## Описание
Найти самый большой квадрат из '1' в матрице и вернуть его площадь.

## Логика решения (DP)
Создаем таблицу `dp`. `dp[i][j]` — сторона квадрата, заканчивающегося в этой точке.
Если элемент '1', берем минимум из соседей (сверху, слева, слева-сверху) и прибавляем 1.

# 859. Buddy Strings

**Сложность:** Easy
**Ссылка:** https://leetcode.com/problems/buddy-strings/

## Описание
Даны две строки `s` и `goal`. Можно ли поменять местами ровно две буквы в `s`, чтобы получить `goal`?

## Логика решения
1. Если длины разные — False.
2. Если строки равны — проверяем наличие повторяющихся букв (set).
3. Если разные — ищем различия. Их должно быть ровно 2, и они должны быть "зеркальными".
